# Final Submission Checklist

- [ ] All required role workflows function locally (see TESTING_CHECKLIST.md).
- [ ] Browser Console has no unexpected errors during demo.
- [ ] Backend health confirms MySQL connected.
- [ ] Uploaded source ZIP includes `frontend/`, `backend/`, schema and README.
- [ ] Exclude `.env`, `node_modules/`, any real student data and exported personal reports.
- [ ] Presentation explains problem, stack, DB schema, roles, APIs, screenshots and results.
- [ ] Demo video shows faculty marking attendance and student viewing history/reports.
- [ ] ZIP extracts correctly on another machine and `npm install` completes.
- [ ] Actual test failures/limitations stated clearly (do not mark tests passed without running them).

**Security caveat:** Static source reviews and offline tests are not substitutes for real end-to-end authorization testing. Default demo accounts are only suitable for local hackathon demonstrations.
