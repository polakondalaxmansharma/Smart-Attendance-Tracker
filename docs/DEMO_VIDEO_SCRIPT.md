# Hackathon Demo Video — 3–5 Minute Sequence

**0:00–0:25 (Introduction):** State problem and objective; show landing/Admin login.
**0:25–1:10 (Admin):** Sign in, show course list and faculty assignment; add one enrollment if necessary.
**1:10–2:20 (Faculty):** Sign in, choose assigned DBMS course, select current date, mark all students Present/Absent, save; open attendance summary.
**2:20–3:15 (Student):** Sign in as enrolled student; show course-wise present/absent counts, percentage, and history. Compare with saved faculty data.
**3:15–3:50 (Reports):** Download faculty or student CSV, briefly open it; use Print / Save PDF.
**3:50–4:15 (DB/closing):** Show read-only MySQL verification query and explain four tables; conclude.

**Before recording:** run `npm run verify`, confirm backend health, clear unwanted browser notifications, avoid revealing `.env`/JWT/passwords, and use demo data only. Keep the backend terminal available to diagnose errors.
